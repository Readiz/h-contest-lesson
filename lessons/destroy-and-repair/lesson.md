# 크게 부수고 다시 짓기

해 하나를 작은 이동으로 계속 고치면 더 이상 좋아지는 이동이 없는 해(지역 최적)에 닿습니다. 거기서 더 나아가려면 해의 일부를 한꺼번에 떼어 내고(부수기) 구성법으로 다시 채워(다시 짓기) 여러 군데를 동시에 바꿔야 할 때가 있습니다. 이 강의는 작은 이동으로 못 나가는 구조가 무엇인지 작은 손계산으로 보이고, 부수고 다시 짓는 반복의 틀과 그 안에서 정할 것(무엇을 몇 개, 어떻게 채울지, 받을지, 어떻게 되돌릴지)을 문제에 상관없이 쓸 수 있는 형태로 다룹니다. 예시는 순서를 정하는 문제와 작업을 기계에 배정하는 문제, 두 가지 연습용 입력입니다.

[문제를 상태·행동·점수로 옮기기](https://h.readiz.com/learn/problem-modeling), [초기해 만들기](https://h.readiz.com/learn/construction-heuristics), [근방 설계와 차분 평가](https://h.readiz.com/learn/neighborhood-and-delta)를 읽었다고 가정합니다. 나쁜 해를 받는 규칙과 온도는 [언덕 오르기와 담금질](https://h.readiz.com/learn/hill-climbing-and-annealing)에서 다루며, 이 강의는 받는 기준이 결과에 주는 영향만 잽니다.

## 이 강의에서 다루는 것

- 작은 이동으로 빠져나오지 못하는 구조(여러 요소를 동시에 바꿔야 좋아지는 경우)와 부수고 다시 짓기의 반복 틀.
- 부술 부분 고르기(무작위·연속 구간·가까운 것·비용 기여·기계 단위)와 다시 짓는 구성법(가장 싼 자리, 후회).
- 새 해를 받는 기준(좋아질 때만, 같아도 받기, 담금질식)과 최고해 보관, 부수는 크기 조절.
- 부수기 전 상태로 되돌리는 방법(복사, 기록, 새 배열에 짓기)과 같은 연산 예산에서 작은 이동만 쓰는 탐색과의 비교.

## 판단 기준 요약

| 상황 | 선택 |
| --- | --- |
| 작은 이동으로 지역 최적 근처까지 왔고 일부를 떼어 내도 다시 채울 수 있다 | 부수고 다시 짓기를 이어서 쓴다 |
| 아직 해가 나쁘고 작은 이동의 평가가 매우 싸다 | 작은 이동을 먼저, 부수고 다시 짓기는 뒤에 |
| 떼어 낼 항목을 고를 때 | 서로 영향을 주는 것끼리(가까운 것, 연속 구간)를 후보로 두고 무작위와 비교한다 |
| 크기, 구성법, 받는 기준을 정할 때 | 한 값만 정하지 않고 같은 예산·같은 시드로 몇 가지를 재 본다 |

## 로컬 연습

1. `runRoute`로 시드 21~30에서 작은 이동만과 혼합을 비교해 실험 페이지의 판정 규칙대로 적습니다.

3. 새 부수기 방법을 하나 고안해 `destroy`에 추가하고 `checkDR`을 통과시킵니다.
4. 되돌리는 방법을 복사와 기록으로 바꿔 반복당 연산을 세고, 이득이 사라지는 크기를 찾습니다.
