# 정보가 부분적일 때 결정하기

가까운 곳만 보이거나 작업이 하나씩 도착하는 문제에서는 입력 전체를 모른 채 결정해야 합니다. 이 강의는 아는 것·관측해서 기억한 것·아직 모르는 것을 나누고, 관측을 거울 상태로 기억해 채점기와 어긋나지 않는지 확인하고, 모르는 값을 추정해 결정하고, 새 관측마다 다시 계획하고, 전체 정보로 푼 결과와 비교해 부분 정보의 비용을 재는 방법을 문제에 상관없이 쓸 수 있는 형태로 다룹니다. 예시는 보이는 거리가 2인 격자 수집(주)과 작업이 하나씩 도착하는 온라인 배정, 두 가지 연습용 입력입니다.

[문제를 상태·행동·점수로 옮기기](https://h.readiz.com/learn/problem-modeling)와 [빔 서치와 평가 함수](https://h.readiz.com/learn/beam-search)를 읽었다고 가정합니다. 빔 서치는 계획기와 전체 정보 기준선으로 쓰이며 이 강의가 다시 설명하지 않습니다. 모르는 값의 확률 모델에서 최적 정책을 구하는 정식 이론(강화학습·베이즈 최적 등)은 이 강의의 범위 밖이고, 설정을 비교하는 실험 설계는 [실험과 튜닝](https://h.readiz.com/learn/experiments-and-tuning)에서 다룹니다.

## 이 강의에서 다루는 것

- 아는 것·관측한 것·모르는 것을 나누는 표, 관측을 기억하는 자료구조(본 값, 마지막으로 본 시점, 밟은 칸, 처음 본 것만 더하는 평균 재료).
- 채점기의 실제 상태를 따라 그리는 거울 상태와, 어긋남을 매 걸음 잡는 거울 대조·추정 지도 대조·엿보기 검사.
- 모르는 값의 추정(비관·평균·낙관)과 각각의 행동 차이, 탐색(모르는 곳을 보러 가기)과 활용(아는 좋은 곳으로 가기)의 균형.
- 새 관측마다 다시 계획하는 방법과 재계획 주기와 평가 횟수의 교환.
- 전체 정보 기준선과의 비교(같은 계획기에 진짜 지도, 5번 강의의 빔, 문제의 한계)와 흔한 실수 5가지.

## 판단 기준 요약

| 상황 | 선택 |
| --- | --- |
| 입력의 일부만 보이고 행동이 다음에 볼 것을 바꾼다 | 거울에 기억하고 추정 지도 위에서 계획하며 새 관측마다 다시 계획한다 |
| 도착하는 대로 결정하고 되돌릴 수 없다 | 탐색할 것도 다시 계획할 것도 없다. 앞으로 올 것의 추정이 쟁점이다 |
| 모르는 값을 채워야 한다 | 관측의 평균으로 시작하고, 비관·낙관과 비교한다. 단위를 아는 값과 맞춘다 |
| 점수가 오르는데 이유가 불확실하다 | 못 본 값을 바꿔도 같은 행동이 나오는지(엿보기 검사)와 거울 대조를 먼저 본다 |
| 부분 정보가 얼마나 손해인지 알고 싶다 | 같은 입력을 다 아는 기준선과 같은 시드끼리 비교하고 정보의 몫과 계획기의 몫을 나눈다 |

## 대표 실험

시드 20개의 점수 중 10번째로 작은 값입니다(격자 ↑ 클수록, 배정 ↓ 작을수록 좋음). 추정, 보이는 거리, 재계획 주기, 깊이와 폭, 입력 밀도, 흔한 실수 검사의 결과는 [실험과 점검](pages/practice.md)에 있습니다.

## 본문

2. [구현: 거울·추정 지도·계획기와 두 문제 유형](pages/implementation.md): 한 판 루프·거울 대조·엿보기 검사와 문제마다 채우는 거울 필드·추정·결정을 두 유형에서 구현합니다.
3. [실험과 점검](pages/practice.md): 추정·거리·주기·깊이별 점수와 평가 횟수, 부분 정보의 비용, 입력 변형, 흔한 실수와 검사, 점검 목록, 적용 사례.
