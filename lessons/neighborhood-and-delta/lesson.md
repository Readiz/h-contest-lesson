# 근방 설계와 차분 평가

해 하나가 이미 있고 그것을 조금씩 바꿔 점수를 올리는 지역 탐색에서는 같은 연산 예산 안에 이동을 얼마나 많이 평가하느냐가 결과를 가릅니다. 이 강의는 해를 조금 바꾸는 이동을 설계하고(근방), 이동이 바꾸는 항만 골라 점수 변화를 계산하고(차분 평가), 그 계산이 맞는지 전체 재계산과 대조하는 방법을 문제에 상관없이 쓸 수 있는 형태로 다룹니다. 예시는 순서를 정하는 문제와 작업을 기계에 배정하는 문제, 두 가지 연습용 입력입니다.

[문제를 상태·행동·점수로 옮기기](https://h.readiz.com/learn/problem-modeling)와 [초기해 만들기](https://h.readiz.com/learn/construction-heuristics)를 읽었다고 가정합니다. 나쁜 이동을 받아들이는 규칙은 [언덕 오르기와 담금질](https://h.readiz.com/learn/hill-climbing-and-annealing)에서 다루며, 이 강의의 실험은 "좋아지면 받는다"만 씁니다.

## 이 강의에서 다루는 것

- 이동의 종류(교환·옮기기·뒤집기·맞바꾸기)와 각 이동이 건드리는 항.
- 근방의 크기와 연결성: 어떤 해에서든 다른 해로 갈 수 있는가.
- 점수식을 항으로 나누고, 건드리는 항을 표시하고, 전후 차이만 계산하는 차분 유도 절차.
- 차분을 전체 재계산과 무작위·전수 이동으로 대조하는 검사 틀과 흔한 실수 4가지.
- 유효성을 깨지 않는 이동(옮기기는 받는 쪽 여유 확인, 맞바꾸기는 항상 유효)과 계산만 하기·적용 후 복구의 선택.

## 판단 기준 요약

| 상황 | 선택 |
| --- | --- |
| 점수가 항의 합이고 이동이 일부 항만 건드린다 | 차분 평가 + 계산만 하고 수락 시 적용 |
| 평가에 이동 뒤의 해가 필요하다 | 적용 후 복구, `apply`·`undo`를 싸게 |
| 이동 하나로 연결이 안 된다(작업 수 고정 등) | 이동을 섞거나 이동을 크게 한다 |
| 차분 식을 새로 유도했다 | 전체 재계산 대조(작은 입력 전수 + 큰 입력 무작위 + 규칙 한계 입력) |

## 대표 실험

## 본문

1. [원리: 이동·근방·차분과 손으로 따라가는 예](pages/idea.md): 이동의 종류, 근방의 크기와 연결성, 차분 유도 3단계를 점 7개 경로와 작업 6개·기계 3대의 손계산으로 따라갑니다.
2. [구현: 이동·차분·검사 틀과 두 문제 유형](pages/implementation.md): 문제와 무관한 탐색 루프·차분 검사와 문제마다 채우는 `propose`·`delta`·`apply`·`undo`를 두 유형에서 구현합니다.
3. [실험과 점검](pages/practice.md): 전체 재계산 대 차분, 이동 종류별 비교, 흔한 실수와 검사, 다른 문제에 옮길 때의 점검 목록, 적용 사례.

## 로컬 연습

1. 구현 페이지의 `Route`로 구간 뒤집기만 쓰는 탐색을 시드 1~20에서 돌려 실험 페이지의 값과 맞춥니다.
2. `delta`의 항을 하나 일부러 빼고 `checkDelta`가 몇 번째 제안에서 잡는지 기록합니다.
3. 직접 고른 새 이동(예: 연속한 세 점 옮기기)을 추가하고 항 표를 적어 전수 검사를 통과시킵니다.
4. 두 이동 구성의 비교를 시드 20개로 짝지어 하고 "더 좋음·더 나쁨·결정 못 함"을 판정합니다.
