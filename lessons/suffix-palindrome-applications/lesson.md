# Suffix and Palindrome Applications

Suffix와 Palindrome 응용은 독립 레슨 카드가 아니라 [Palindrome Structures](https://h.readiz.com/learn/palindrome-structures) 허브의 하위 페이지로 이동했습니다.

- 새 위치: [Palindrome Structures / Suffix and Palindrome Applications](https://h.readiz.com/learn/suffix-periodicity-structures/suffix-automaton)
- 함께 읽을 페이지: [Palindrome Model Map](https://h.readiz.com/learn/palindrome-structures), [Palindromic Tree](https://h.readiz.com/learn/palindrome-structures/palindromic-tree)

이 이동 문서는 기존 링크를 따라온 독자를 안내하기 위해 남깁니다. manifest의 공개 레슨 목록에서는 `palindrome-structures` 허브만 노출합니다.
