# 실전 C++ 기본기와 공통 코드

휴리스틱 풀이를 시작할 때의 첫 목표는 **문제의 공개 API만으로 유효한 답을 끝까지 만드는 것**입니다. 이 레슨은 h-contest의 함수 구현형 `user.cpp` 환경을 기준으로, STL과 표준 헤더 없이 사용할 작은 공통 코드를 준비합니다.

변수·반복문·함수·배열의 기초 문법은 알고 있다고 가정합니다. `struct`, 참조, `template`는 C++ 언어 기능이므로 사용할 수 있습니다. STL을 쓰지 않는다는 이유로 이들까지 없앨 필요는 없습니다.

처음에는 1 → 2 → 4 순서로 읽어도 됩니다. 3의 정렬·큐·힙은 해당 작업이 필요한 문제를 만났을 때 돌아옵니다. 모든 자료구조를 먼저 암기할 필요는 없습니다.

## 공통 코드를 쓰는 규칙

- 각 코드 블록은 독립적으로 복사할 수 있습니다. 같은 블록은 한 번만 넣습니다. `hc` namespace는 공통 코드와 문제 API의 이름 충돌을 줄입니다.
- 각 블록에 적힌 **용량, 인덱스 범위, 초기화 시점, 실패 반환값**을 함께 가져갑니다. 문제마다 최대 크기를 다시 계산합니다.
- 공개된 `user.cpp`의 함수 시그니처는 유지합니다. `main`, 헤더, 로컬 검증 코드를 제출 파일에 덧붙이지 않습니다.
- 필요한 블록만 개인 스니펫으로 보관할 수 있습니다. 공통 코드의 원문은 이 레슨이며, 문제별 상태·평가 함수·이동 연산은 풀이 쪽에 둡니다.
- 다른 레슨에서 같은 코드를 쓰면 이 레슨의 블록 이름과 필요한 설정을 명시합니다. 기존 레슨 전체의 STL 예제 전환은 개편 로드맵에 따라 순차적으로 진행합니다.
