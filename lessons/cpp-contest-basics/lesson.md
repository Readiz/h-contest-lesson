# 실전 C++ 기본기와 공통 코드

휴리스틱 풀이를 시작할 때의 첫 목표는 **문제의 공개 API만으로 유효한 답을 끝까지 만드는 것**입니다. 이 레슨은 h-contest의 함수 구현형 `user.cpp` 환경을 기준으로, STL과 표준 헤더 없이 사용할 작은 공통 코드를 준비합니다.

변수·반복문·함수·배열의 기초 문법은 알고 있다고 가정합니다. `struct`, 참조, `template`는 C++ 언어 기능이므로 사용할 수 있습니다. STL을 쓰지 않는다는 이유로 이들까지 없앨 필요는 없습니다.

## 읽는 순서

| 순서 | 페이지 | 끝나고 할 수 있는 일 |
| --- | --- | --- |
| 1 | [제출 계약과 상태 초기화](pages/submission-and-state.md) | 호출 순서·제한·점수 방향을 읽고, 여러 TC에서 같은 풀이를 재현한다 |
| 2 | [배열과 재현 가능한 난수](pages/arrays-and-random.md) | 복사·초기화·순열 셔플을 필요한 부분만 가져다 쓴다 |
| 3 | [정렬·큐·최소 힙](pages/sorting-queue-heap.md) | 후보의 처리 순서에 맞는 자료구조를 고르고 용량을 계산한다 |
| 4 | [작은 검증부터 ORDERING까지](pages/practice.md) | 공통 코드의 경계를 검사하고, 실제 채점기로 유효한 기준선을 만든다 |

처음에는 1 → 2 → 4 순서로 읽어도 됩니다. 3의 정렬·큐·힙은 해당 작업이 필요한 문제를 만났을 때 돌아옵니다.

각 코드 블록은 독립적으로 복사할 수 있습니다. 필요한 블록만 한 번씩 넣고, 해당 문제의 배열 상한과 초기화 시점을 맞춥니다. `hc` namespace는 공개 API와의 이름 충돌을 줄이기 위한 것입니다.

필요한 블록을 개인 스니펫으로 보관해도 됩니다. 문제별 상태·평가 함수·이동 연산은 풀이 쪽에 둡니다.
