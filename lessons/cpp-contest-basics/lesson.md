# 실전 C++ 기본기와 공통 코드

휴리스틱 풀이를 시작할 때의 첫 목표는 **문제의 공개 API만으로 유효한 답을 끝까지 만드는 것**입니다. 이 레슨은 h-contest의 함수 구현형 `user.cpp` 환경을 기준으로, STL과 표준 헤더 없이 사용할 작은 공통 코드를 준비합니다.

변수·반복문·함수·배열의 기초 문법은 알고 있다고 가정합니다. `struct`, 참조, `template`는 C++ 언어 기능이므로 사용할 수 있습니다. STL을 쓰지 않는다는 이유로 이들까지 없앨 필요는 없습니다.

## 읽는 순서

| 순서 | 페이지 | 끝나고 할 수 있는 일 |
| --- | --- | --- |
| 1 | [제출 계약과 상태 초기화](pages/submission-and-state.md) | 호출 순서·제한·점수 방향을 읽고, 여러 TC에서 같은 풀이를 재현한다 |
| 2 | [배열과 재현 가능한 난수](pages/arrays-and-random.md) | 복사·초기화·순열 셔플을 필요한 부분만 가져다 쓴다 |
| 3 | [정렬·큐·최소 힙](pages/sorting-queue-heap.md) | 후보의 처리 순서에 맞는 자료구조를 고르고 용량을 계산한다 |
| 4 | [작은 검증부터 ORDERING까지](pages/practice.md) | 공통 코드의 경계를 검사하고, 실제 채점기로 유효한 기준선을 만든다 |

처음에는 1 → 2 → 4 순서로 읽어도 됩니다. 3의 정렬·큐·힙은 해당 작업이 필요한 문제를 만났을 때 돌아옵니다.

각 코드 블록은 독립적으로 복사할 수 있습니다. 필요한 블록만 한 번씩 넣고, 해당 문제의 배열 상한과 초기화 시점을 맞춥니다. `hc` namespace는 공개 API와의 이름 충돌을 줄이기 위한 것입니다.

필요한 블록을 개인 스니펫으로 보관해도 됩니다. 문제별 상태·평가 함수·이동 연산은 풀이 쪽에 둡니다.

## 일반 C++ 예제를 제출 코드로 옮길 때

다른 레슨의 **일반 C++17 학습용** 표시는 알고리즘을 로컬에서 익히기 위한 예제라는 뜻입니다. h-contest에 옮길 때는 먼저 문제의 공개 함수·인덱스·입력 상한을 확인하고 아래처럼 필요한 자료구조를 바꿉니다.

| 학습용 예제 | 공통 코드로 옮기는 기준 |
| --- | --- |
| `vector`와 동적 배열 | 입력 상한에 맞춘 고정 배열과 현재 길이를 둡니다. TC마다 사용할 구간을 초기화합니다. |
| `sort`로 후보 순서 결정 | `index-sort` 블록처럼 ID를 정렬합니다. 점수 외 우선순위가 있으면 비교 규칙과 같은 값의 순서를 명시합니다. |
| BFS의 `queue` | `queue` 블록을 쓰고 중복 삽입을 막습니다. 단순 배열 큐는 최대 동시 원소 수가 아니라 초기화 이후 총 삽입 수로 용량을 잡습니다. |
| Dijkstra의 `priority_queue` | `min-heap` 블록에서 비용과 정점 ID를 저장합니다. 오래된 후보를 꺼냈을 때 버리는 조건과 중복 삽입까지 포함한 용량을 유지합니다. |
| 포인터로 할당하는 트리 노드 | 문제의 연산 상한으로 노드 풀을 잡고 정수 인덱스로 연결합니다. 이 레슨의 큐·힙 코드만으로 트리 구현까지 대체되지는 않습니다. |

전체 연결 예시는 [ORDERING의 제출 코드](https://h.readiz.com/learn/heuristic/ordering-route-improvement)와 [공통 난수를 붙이는 SA 확장](https://h.readiz.com/learn/heuristic/search-strategies)에서 확인할 수 있습니다.
