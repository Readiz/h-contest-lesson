# Monte Carlo Tree Search

Monte Carlo Tree Search는 독립 레슨 카드가 아니라 [Probabilistic Decision AI](https://h.readiz.com/learn/probabilistic-decision-ai) 허브의 하위 페이지로 이동했습니다.

- 새 위치: [Probabilistic Decision AI / Monte Carlo Tree Search](https://h.readiz.com/learn/probabilistic-decision-ai/monte-carlo-tree-search)
- 함께 읽을 페이지: [Decision AI Model Map](https://h.readiz.com/learn/probabilistic-decision-ai), [POMCP](https://h.readiz.com/learn/probabilistic-decision-ai/pomcp)

이 이동 문서는 기존 링크를 따라온 독자를 안내하기 위해 남깁니다. manifest의 공개 레슨 목록에서는 `probabilistic-decision-ai` 허브만 노출합니다.
